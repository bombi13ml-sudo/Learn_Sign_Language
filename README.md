# SignLanguage
Ang SIGNED o "Senyas ay Ilaw at Gabay sa Nangangailangan ng Edukasyon” ay isang libreng online na diksyunaryo ng Filipino Sign Language (FSL) na dinisenyo para sa lahat. Ito ay para sa mga gustong matuto, sa mga kaibigan ng Deaf community, at sa mga nagnanais na makipag-ugnayan nang mas malawak.

Dito makikita mo ang mga video tutorial ng bawat letra sa alpabeto at ng mga karaniwang parirala, na ginawa upang maging madali, masaya, at accessible para sa lahat ng edad.
